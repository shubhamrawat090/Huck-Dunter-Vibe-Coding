# Duck Hunter Game

This is a simple Duck Hunter game built with HTML, CSS, and JavaScript.

## How to Play

1.  Clone this repository or download the files from the `DuckHunter` folder.
2.  Open the `index.html` file in your web browser.
3.  Click the "Start Game" button to begin.
4.  Ducks will start flying up from the bottom of the screen.
5.  Click on the ducks to shoot them and earn points.
6.  The game lasts for 60 seconds.
7.  Try to get the highest score before time runs out!

## Files

*   `index.html`: The main HTML structure of the game, including the canvas and score display.
*   `style.css`: Contains the CSS styles for the game's appearance.
*   `script.js`: Contains the JavaScript logic for game mechanics, including duck movement, shooting, scoring, and the timer.
